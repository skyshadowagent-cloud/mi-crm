# Mi CRM

Página de presentación de **Mi CRM**: gestión de clientes y e-commerce de productos digitales.

## Características

- Gestión de clientes
- E-commerce de productos digitales
- Automatización con IA
- Panel de analíticas y reportes
- Integraciones (email, WhatsApp, pagos)
- Flujos de trabajo automatizados

## Desarrollo local

```bash
npm start
```

La app arranca en `http://localhost:3000` (o en el puerto definido por `PORT`).

## Despliegue en Railway

Este proyecto incluye `package.json` con el script `start`, por lo que Railway
detecta el proyecto Node automáticamente y lo despliega sin configuración adicional.
